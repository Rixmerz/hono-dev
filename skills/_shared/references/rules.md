# Validator rules

The 36 rules the validator runs over the composed route table. Every finding carries the rule
`id`, a `severity`, the `file` and `line` it points at, a `message`, a `hint`, and a
`confidence`: `extracted` when the rule read it straight from source, `inferred` when it
rests on a heuristic (a name that looks like auth, a body use it could not follow). A finding
with severity `error` makes the result `ok: false` and the command-line `validate` exit 1.

Run one category while you work, all of them before you finish:
`hono_validate(workspace="/abs/path", categories=["routes"], files=["src/app.ts"])`.
`fast=true` skips the two slow rules (A004, C004). `files` keeps only findings located in
those files. Paths are workspace-relative, with no leading `./`.

Rules read the model the core builds (`routes`, `middlewares`, `mounts`, `apps`, `rpc`,
`envReads`, `envValidation`, `detection`, `config`) and the per-file facts behind it; the last
column says which. The project's own conventions outrank every rule: a finding on code that
is deliberate is acknowledged in a comment, not silenced by a rewrite.

## routes

| ID   | Severity | Category | What it flags                                                                                                                                                                    | How to fix                                                              | Facts it reads                                               |
| ---- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------ |
| R001 | error    | routes   | the same method and full path registered twice in one root table; the first answers, the second never runs. Skips pairs where either registration sits in an `if`, loop or `try` | delete one, or change a method or path                                  | `RootTable.entries` (`method`, `fullPath`, `confidence`)     |
| R002 | warning  | routes   | a param or wildcard route registered before a static route it also matches (`/users/:id` before `/users/me`)                                                                     | register the static route first, or constrain the param (`:id{[0-9]+}`) | `RootTable.entries`, `RootTable.matcher` (hono's own router) |
| R003 | error    | routes   | a route (or middleware) added to a sub-app after `route()` mounted it: the parent copied the table at that moment                                                                | move the registration above the `route()` call                          | `composition.stranded`                                       |
| R004 | warning  | routes   | a Hono instance with routes that no `route()` mounts and nothing serves. Inferred when some `route()` call elsewhere could not be resolved                                       | mount it, serve it, or delete it                                        | `RootTable.live`, `AppNode`, compose warnings in `skipped`   |
| R005 | info     | routes   | a route path, `route()` prefix or `basePath()` argument that is not a string literal: it is invisible to traces and to the other route rules                                     | use a literal or a same-file `const` string                             | `ModuleFacts.ops` (`PathValue.literal`)                      |
| R006 | warning  | routes   | a path with no leading slash, a `//`, or a route that duplicates another up to the trailing slash                                                                                | write `/segment`; keep one form or set `strict: false`                  | `ModuleFacts.ops`, `RootTable.entries`                       |
| R007 | info     | routes   | one sub-app mounted at two prefixes: every route exists once per mount. Fine for versioned aliases                                                                               | mount it once, or keep and say why                                      | `mounts` (`kind: route`)                                     |

## middleware

| ID   | Severity | Category   | What it flags                                                                                                                                                                    | How to fix                                          | Facts it reads                                           |
| ---- | -------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------- |
| M001 | warning  | middleware | `use()` registered after routes on the same instance that its path covers: they are matched first and never run through it                                                       | move `use()` above the routes                       | `MiddlewareEntry.registeredAfterRoutes`, `mountChain`    |
| M002 | warning  | middleware | a parent `use()` registered after the `route()` mount whose routes it would cover                                                                                                | write `use()` before the `route()` call             | same, plus `mounts` (route hops against `basePath` hops) |
| M003 | warning  | middleware | a scoped `use('/x/*')` whose path matches no route of the table. Inferred. Exempts `serveStatic`                                                                                 | fix the path or delete it                           | `RootTable.entries`, `RootTable.matcher`                 |
| M004 | warning  | middleware | a middleware that declares `next` and neither calls nor forwards it (`mw(c, next)` counts as forwarding); a function with no `next` parameter is a terminal handler, not flagged | `await next()` or return a Response on every path   | `MiddlewareFnFacts`, `RawFn.nextPassed`                  |
| M005 | warning  | middleware | `next()` called without `await` or `return`: code after it runs early and the response is lost                                                                                   | `await next()` or `return next()`                   | `MiddlewareFnFacts.awaitsOrReturnsNext`                  |
| M006 | warning  | middleware | the same middleware (same name, source and argument text) twice in one route's chain: it runs twice                                                                              | register it once on the narrowest covering instance | `RouteEntry.chain`                                       |
| M007 | error    | middleware | `cors()` after an auth middleware on the same route: the preflight (no credentials) is answered 401                                                                              | register `cors()` before auth                       | `RouteEntry.chain` (`isAuth`, `name`)                    |

## validation

| ID   | Severity | Category   | What it flags                                                                                                                                                                                                        | How to fix                                                                   | Facts it reads                                     |
| ---- | -------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------- |
| V001 | warning  | validation | POST, PUT or PATCH whose handler reads `c.req.json()`, `parseBody()` or `formData()` with no json or form validator in the chain. Raw `text()`, `arrayBuffer()`, `blob()` reads (webhook signatures) are not flagged | `zValidator('json', schema)` (or the project's validator) before the handler | `HandlerFacts.bodyReads`, `RouteEntry.validators`  |
| V002 | info     | validation | a body route with no validator whose handler cannot be read: it hands `c`, `c.req` or `c.req.raw` to other code, is built by a factory, or is not resolvable. Inferred; acknowledge it when the callee validates     | validate before delegating, or leave and say why                             | `HandlerFacts.kind`, `resolved`, `requestEscapes`  |
| V003 | error    | validation | `c.req.valid('x')` with no validator for target `x` in the chain: it returns `undefined`                                                                                                                             | add the validator for that target                                            | `HandlerFacts.validReads`, `RouteEntry.validators` |
| V004 | warning  | validation | a json or form validator on a GET or HEAD route: there is no body to validate                                                                                                                                        | validate `query`, or make the route a POST                                   | `RouteEntry.validators` (`scope: route`)           |
| V005 | info     | validation | route params read with `c.req.param()` and no `param` validator                                                                                                                                                      | validate ids with a `param` validator                                        | `HandlerFacts.paramReads`                          |

## security

| ID   | Severity | Category | What it flags                                                                                                                                                                                                                                                                                                                                                                                            | How to fix                                                                                  | Facts it reads                                |
| ---- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------- |
| S001 | error    | security | `cors()` with `credentials: true` and an origin that is `'*'`, absent (the default is `'*'`), or a function that returns its own argument                                                                                                                                                                                                                                                                | list the allowed origins                                                                    | `MiddlewareEntry.options`                     |
| S002 | warning  | security | a route with no auth where (a) a path-scoped auth middleware covers its path but sits after it in the table because a sibling mount was registered first (the known OAuth-callback case), or (b) more than half of the routes of its own sub-app (at least three) are guarded. Inferred. A guard written after its routes on the same instance is M001/M002, not S002                                    | keep and comment if public on purpose; otherwise mount after the guarded parent or guard it | `RouteEntry.chain`, `unreached`, `mountChain` |
| S003 | warning  | security | a secret-looking env key (`SECRET`, `TOKEN`, `PASSWORD`, `PRIVATE`, `CREDENTIALS`, `API_KEY`, `KEY` as a name segment, `DATABASE_URL`, `DSN`) read with no validation. A schema that names the key, or a hand-written guard (`if (!x) throw` or `return` before use, on the bound variable or the read itself), validates it for the whole project; a schema over the whole env covers its own file only | parse the env once at startup, or fail when the key is missing                              | `envReads`, `envValidation`                   |
| S004 | error    | security | a literal string at `secret` (`jwt`), `token` (`bearerAuth`) or `password` (`basicAuth`)                                                                                                                                                                                                                                                                                                                 | read it from the environment                                                                | `ModuleFacts.ops` args, import specifier      |
| S005 | warning  | security | an `onError` that puts `err.message`, `err.stack` or the raw error in the response (an `err instanceof HTTPException` branch is exempt)                                                                                                                                                                                                                                                                  | log it, answer a generic body                                                               | `RawFn.leaksError`, `composition.resolveFn`   |
| S006 | warning  | security | a cookie or session auth middleware guarding POST, PUT, PATCH or DELETE routes with no `csrf()` in their chain. Inferred                                                                                                                                                                                                                                                                                 | add `csrf()` from `hono/csrf`                                                               | `MiddlewareEntry`, `RouteEntry.chain`         |
| S007 | info     | security | `formData()` or `parseBody()` read with no `bodyLimit()` in the chain                                                                                                                                                                                                                                                                                                                                    | `bodyLimit({ maxSize })` from `hono/body-limit`                                             | `HandlerFacts.bodyReads`, `RouteEntry.chain`  |

## architecture

| ID   | Severity       | Category     | What it flags                                                                                                                                    | How to fix                                                          | Facts it reads                                |
| ---- | -------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- | --------------------------------------------- |
| A001 | warning        | architecture | a route handler that calls a DB client, or a module that opens one, outside `config.serviceDirs` (default `src/services`, `services`, `src/lib`) | move the query into a service and call that                         | `HandlerFacts.dbAccess`, `config.serviceDirs` |
| A002 | warning        | architecture | a served root app that never calls `onError`                                                                                                     | `app.onError((err, c) => ...)` that logs and answers a generic body | `AppNode.errorHandler`, `composition.served`  |
| A003 | info           | architecture | a served root app that never calls `notFound`                                                                                                    | `app.notFound((c) => c.json({ error: 'Not found' }, 404))`          | `AppNode.notFoundHandler`                     |
| A004 | warning (slow) | architecture | an import cycle through two or more route modules (value imports only): one runs before the other is defined                                     | break the cycle; import from where it is defined                    | `graph.importsOf`                             |

## rpc

| ID   | Severity | Category | What it flags                                                                                                            | How to fix                                                   | Facts it reads                       |
| ---- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------ |
| P001 | warning  | rpc      | an exported `type AppType = typeof app` where `app` has routes but is not built by one chain: the client type has none   | build the app as one chain and take the type from its result | `rpc.appTypes` (`chained`, `target`) |
| P002 | warning  | rpc      | `hc<T>()` where `T` is not an exported app type; a type imported from another package, or a computed type, is not judged | export the app type and import it                            | `rpc.clients` (`typeArg`, `appType`) |

## conventions

| ID   | Severity    | Category    | What it flags                                                                                                                                                                                                                                                                                                                    | How to fix                                                  | Facts it reads                                     |
| ---- | ----------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------- |
| C001 | error       | conventions | a runtime API that does not match the runtime: `Deno.env` on Node, `c.env` on Node (`incoming` and `outgoing` excepted), `process.env` on Workers unless `nodejs_compat` / `nodejs_compat_v2` is set or `compatibility_date` is 2026-08-04 or later (and `no_nodejs_compat` is not). | C004 | info (slow) | conventions | a route module that no test imports and whose static path prefixes no test text contains. ## Deprecated Hono APIs (C003)

Authoritative for the validator. Read from `@deprecated` in `dist/types/**` of `hono@4.13.16`;
a newer Hono may deprecate more. The list holds what can be seen in source; type-only
deprecations that no source text names are left out.

| API                                                                                                                                                            | Replacement                                                                                     | Where deprecated                         | How C003 sees it                           |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------- | ------------------------------------------ |
| `app.mount(path, handler)`                                                                                                                                     | `app.all('/p/*', mount(handler))` with `mount` from `hono/mount`                                | `hono-base.d.ts`                         | a `mount` registration on a Hono instance  |
| `app.fire()`                                                                                                                                                   | `fire` from `hono/service-worker` (itself deprecated: `@hono/service-worker`)                   | `hono-base.d.ts`                         | a no-argument `.fire()` on a Hono instance |
| `c.req.routePath`, `c.req.matchedRoutes`                                                                                                                       | `routePath(c)`, `matchedRoutes(c)` from `hono/route`                                            | `request.d.ts`                           | the member access on `c.req`               |
| `hono/aws-lambda`, `hono/bun`, `hono/cloudflare-workers`, `hono/deno`, `hono/lambda-edge`, `hono/netlify`, `hono/service-worker`, `hono/vercel` (every export) | the `@hono/<name>` package of the same name                                                     | `dist/types/adapter/**`                  | an import of that specifier                |
| `hono/cloudflare-pages` (every export)                                                                                                                         | `hono` on Workers with static assets                                                            | `dist/types/adapter/cloudflare-pages/**` | an import of that specifier                |
| `bearerAuth` options `noAuthenticationHeaderMessage`, `invalidAuthenticationHeaderMessage`, `invalidTokenMessage`                                              | `noAuthenticationHeader.message`, `invalidAuthenticationHeader.message`, `invalidToken.message` | `middleware/bearer-auth/index.d.ts`      | the key in the literal options             |
| `serveStatic` option `pathResolve`                                                                                                                             | none: it is no longer used                                                                      | `middleware/serve-static/index.d.ts`     | the key in the literal options             |
| `getQueryStrings` from `hono/utils/url`                                                                                                                        | the `URL` API                                                                                   | `utils/url.d.ts`                         | the import name                            |
| `UnOfficalStatusCode` from `hono/utils/http-status`                                                                                                            | `UnofficialStatusCode`                                                                          | `utils/http-status.d.ts`                 | the import name                            |
| `SSG_DISABLED_RESPONSE` from `hono/ssg`                                                                                                                        | `X_HONO_DISABLE_SSG_HEADER_KEY`                                                                 | `helper/ssg/middleware.d.ts`             | the import name                            |

## Configuration that changes a rule

Read from `.hono-dev/config.json` in the analysed project (the plugin never writes it):
`serviceDirs` (A001), `authMiddleware` (which names count as auth for M007, S002 and S006), `dbSpecifiers` (A001), `envValidationModules` (S003: reads inside those files count as
validated).
